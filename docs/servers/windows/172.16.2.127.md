## Configuración de cliente WinRM requerida (en esta máquina, no en el
repo)

A diferencia de SSH, WinRM no usa un archivo de config versionable por
host — requiere que el servicio `WinRM` local esté corriendo y que el
host esté en la lista de confianza del cliente:

```powershell
Get-Service WinRM                                    # debe estar Running
(Get-Item WSMan:\localhost\Client\TrustedHosts).Value # debe incluir 172.16.2.127
```

**Estado de esta configuración:** el servicio `WinRM` local estaba
`Stopped`/`Manual` y `TrustedHosts` estaba vacío — se corrigió el
2026-09-08 con aprobación explícita del usuario: `Start-Service WinRM` +
`Set-Item WSMan:\localhost\Client\TrustedHosts -Value '172.16.2.127'
-Concatenate -Force` (agregado, no reemplazó nada porque estaba vacío).
