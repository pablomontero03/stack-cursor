# Instrucciones del proyecto BaseDatos y Schema Sync

## Alcance

Aplicar estas reglas cuando se trabaje dentro de automation/schema-sync, proyectos SSDT, definiciones n8n o configuración de sincronización BD hacia repositorio.

## Seguridad SQL

- Tratar todas las bases como fuentes de solo lectura.
- Permitir únicamente SqlPackage /Action:Extract y consultas de metadatos de solo lectura.
- Utilizar ApplicationIntent=ReadOnly.
- No ejecutar SqlPackage Publish o Deploy.
- No utilizar TargetConnectionString.
- No ejecutar INSERT, UPDATE, DELETE, MERGE, CREATE, ALTER, DROP o TRUNCATE contra SQL.
- No ejecutar GRANT, REVOKE ni cambios de roles o permisos.
- Si una corrección requiere modificar la BD, detenerse y reportarla como acción DBA separada.
- PublishChangesToProject puede modificar archivos SSDT en disco, pero nunca la BD.

## Ejecución de sincronizaciones

- Operar una sola base de datos por vez.
- Confirmar el nombre real de la BD antes de ejecutar.
- Leer databases.json como fuente de verdad.
- No asumir que database, repoName y projectName son iguales.
- No ejecutar run-batch.sh --execute salvo solicitud explícita.
- No ejecutar ScHmSyNcOrCh0001 salvo solicitud explícita.
- Mantener do_not_auto_run=true en el orquestador.
- No habilitar automáticamente schedules ni workflows.
- No habilitar Softland en n8n o databases.json.

## Bases nuevas y cascarón SSDT

- Antes de incorporar una BD, revisar si el repo está vacío o contiene solo
  README y carece de .sqlproj, .slnx y build-dacpac.ps1.
- Crear cascarón únicamente en ese caso; no reemplazar un proyecto existente.
- Utilizar un ProjectGuid nuevo y no copiarlo desde una plantilla.
- Compilar el cascarón con cero errores antes de importar el esquema.
- Para bases grandes, preferir Source=DACPAC y Target=proyecto vacío si el
  Compare live presenta timeout.
- No crear workflow n8n ni habilitar databases.json antes de que el proyecto
  compile y el import esté validado.
- No versionar bin, obj, out o archivos DACPAC.

## Azure DevOps

- El flujo autorizado del tool es push automatizado a main.
- Crear o reutilizar PR main hacia release.
- No habilitar autocomplete.
- No completar, aprobar ni abandonar PR automáticamente.
- Informar al usuario antes de una acción que pueda crear commits, push o PR.
- Utilizar los scopes mínimos necesarios.

## Secretos

- No leer, imprimir, copiar o almacenar passwords, PAT, tokens, connection strings completas o archivos de credenciales.
- Mantener secretos en .env, Key Vault o credenciales seguras de n8n.
- Utilizar placeholders en documentación y ejemplos.
- No incluir secretos en workflows exportados.

## Fuentes de verdad

- Operación cotidiana: automation/schema-sync/README.md.
- Historia, arquitectura e incidentes: automation/schema-sync/CONTEXTO-COMPLETO.md.
- Catálogo actual: automation/schema-sync/databases.json.
- Bundle especial: automation/schema-sync/bundles/core-workflow-global.json.
- Código real: automation/schema-sync/SchemaSyncTool/ y runners existentes.

## Validación

- Validar JSON después de modificar catálogos o workflows.
- Ejecutar bash -n después de modificar scripts shell cuando bash esté disponible.
- Validar sintaxis PowerShell después de modificar archivos ps1.
- Ejecutar dotnet build y pruebas después de modificar SchemaSyncTool.
- No ejecutar una sincronización real como consecuencia automática de un build o prueba.
- Revisar siempre status y buildOk del result JSON.

## Cambios mínimos

- Preservar cambios no relacionados.
- No duplicar catálogos ni mappings en documentación.
- No actualizar cantidades estáticas de bases en varias ubicaciones.
- Proponer primero enabled=false para incorporaciones nuevas.
- Ejecutar una corrida real solamente cuando el usuario la solicite explícitamente.

$ErrorActionPreference = 'Stop'

$rawInput = [Console]::In.ReadToEnd()
if ([string]::IsNullOrWhiteSpace($rawInput)) {
    exit 0
}

$hookInput = $rawInput | ConvertFrom-Json
if ($hookInput.tool_name -ne 'Bash') {
    exit 0
}

$command = [string]$hookInput.tool_input.command
if ([string]::IsNullOrWhiteSpace($command)) {
    exit 0
}

$normalized = $command.ToLowerInvariant()

function Deny-Command {
    param([string]$Reason)
    [Console]::Error.WriteLine("Schema Sync bloqueó el comando: $Reason")
    exit 2
}

if ($normalized -match 'sqlpackage[^\r\n]*(/action:publish|/action:deploy|/targetconnectionstring)') {
    Deny-Command 'Publish, Deploy y TargetConnectionString están prohibidos.'
}

$sqlExecutor = $normalized -match '(sqlcmd|invoke-sqlcmd|ado\.net|system\.data\.sqlclient|microsoft\.data\.sqlclient)'
$sqlMutation = $normalized -match '\b(insert|update|delete|merge|create|alter|drop|truncate|grant|revoke|deny)\b'

if ($sqlExecutor -and $sqlMutation) {
    Deny-Command 'Las operaciones DDL, DML y de seguridad contra SQL están prohibidas.'
}

if ($normalized -match 'schmsyncorch0001' -and $env:SCHEMA_SYNC_ALLOW_BATCH -ne '1') {

$ErrorActionPreference = 'Stop'

$rawInput = [Console]::In.ReadToEnd()
if ([string]::IsNullOrWhiteSpace($rawInput)) {
    exit 0
}

$hookInput = $rawInput | ConvertFrom-Json
$filePath = [string]$hookInput.tool_input.file_path

if ([string]::IsNullOrWhiteSpace($filePath)) {
    $filePath = [string]$hookInput.tool_input.path
}

if ([string]::IsNullOrWhiteSpace($filePath) -or -not (Test-Path -LiteralPath $filePath)) {
    exit 0
}

function Fail-Validation {
    param([string]$Reason)
    [Console]::Error.WriteLine("Validación Schema Sync falló: $Reason")
    exit 2
}

$extension = [IO.Path]::GetExtension($filePath).ToLowerInvariant()
$fileName = [IO.Path]::GetFileName($filePath)

if ($extension -eq '.json') {
    try {
        $null = Get-Content -LiteralPath $filePath -Raw | ConvertFrom-Json
    }
    catch {
        Fail-Validation "JSON inválido en $filePath. $($_.Exception.Message)"
    }
}

if ($extension -eq '.ps1') {
    $tokens = $null
    $errors = $null
    $null = [System.Management.Automation.Language.Parser]::ParseFile(
        $filePath,
        [ref]$tokens,
        [ref]$errors
    )

    if ($errors.Count -gt 0) {
        Fail-Validation "PowerShell inválido en $filePath. $($errors[0].Message)"
    }
}

if ($extension -eq '.sh' -and (Get-Command bash -ErrorAction SilentlyContinue)) {
    & bash -n $filePath
    if ($LASTEXITCODE -ne 0) {
        Fail-Validation "Shell inválido en $filePath."
    }
}

if ($fileName -eq 'databases.json') {
    $rawCatalog = Get-Content -LiteralPath $filePath -Raw

    if ($rawCatalog -match '(?is)"database"\s*:\s*"SOFTLAND".{0,1000}"enabled"\s*:\s*true') {
        Fail-Validation 'SOFTLAND no puede quedar enabled=true sin una decisión explícita y revisión manual.'
    }
}

if ($fileName -match 'multi-bd|orchestrator|orquestador') {
    $rawWorkflow = Get-Content -LiteralPath $filePath -Raw

    if ($rawWorkflow -match '"do_not_auto_run"\s*:\s*false') {
        Fail-Validation 'El orquestador debe conservar do_not_auto_run=true.'
    }
}

exit 0

$ErrorActionPreference = 'Stop'

$rawInput = [Console]::In.ReadToEnd()
$hookInput = $null

if (-not [string]::IsNullOrWhiteSpace($rawInput)) {
    $hookInput = $rawInput | ConvertFrom-Json
}

if ($hookInput -and $hookInput.stop_hook_active -eq $true) {
    exit 0
}

$projectRoot = $env:CLAUDE_PROJECT_DIR
if ([string]::IsNullOrWhiteSpace($projectRoot)) {
    exit 0
}

$schemaRoot = Join-Path $projectRoot 'automation\schema-sync'
if (-not (Test-Path -LiteralPath $schemaRoot)) {
    exit 0
}

function Fail-StopValidation {
    param([string]$Reason)
    [Console]::Error.WriteLine("La revisión final de Schema Sync falló: $Reason")
    exit 2
}

$jsonFiles = Get-ChildItem -LiteralPath $schemaRoot -Filter '*.json' -File -ErrorAction SilentlyContinue
foreach ($jsonFile in $jsonFiles) {
    try {
        $null = Get-Content -LiteralPath $jsonFile.FullName -Raw | ConvertFrom-Json
    }
    catch {
        Fail-StopValidation "JSON inválido: $($jsonFile.FullName)."
    }
}

$toolProject = Join-Path $schemaRoot 'SchemaSyncTool'
if (Test-Path -LiteralPath $toolProject) {
    $gitCommand = Get-Command git -ErrorAction SilentlyContinue
    $dotnetCommand = Get-Command dotnet -ErrorAction SilentlyContinue

    if ($gitCommand -and $dotnetCommand) {
        $changedFiles = & git -C $projectRoot diff --name-only 2>$null
        $toolChanged = $changedFiles | Where-Object { $_ -like 'automation/schema-sync/SchemaSyncTool/*' }

        if ($toolChanged) {
            & dotnet build $toolProject -c Release --no-restore
            if ($LASTEXITCODE -ne 0) {
                Fail-StopValidation 'dotnet build falló para SchemaSyncTool.'
            }
        }
    }
}

exit 0

16. PRUEBAS DE ACEPTACIÓN
======================================================================

- La skill responde estado sin ejecutar nada.
- La skill utiliza databases.json y no una lista estática.
- La skill diferencia database, repo y projectName.
- Un comando SqlPackage Publish queda bloqueado.
- Un comando DDL/DML mediante sqlcmd queda bloqueado.
- Un batch sin flag autorizado queda bloqueado.
- JSON inválido queda detectado.
- PowerShell inválido queda detectado.
- Shell inválido queda detectado cuando bash está disponible.
- Un cambio de SchemaSyncTool ejecuta build final.
- Un repo vacío se detecta como candidato a cascarón.
- Un repo con .sqlproj existente no recibe otro cascarón.
- Cada cascarón genera un ProjectGuid nuevo.
- Un cascarón no habilita databases.json, workflow o schedule.
- bin, obj, out y DACPAC permanecen fuera de Git.
- Softland no puede quedar enabled accidentalmente.
- El orquestador conserva do_not_auto_run=true.
- Un diagnóstico no repite automáticamente el workflow.
- Una ejecución de una BD entrega result JSON, buildOk y PR.
- Ningún flujo completa PR automáticamente.
- Ningún flujo escribe en SQL.
