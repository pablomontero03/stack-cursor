# Diagnóstico — windows-server-diagnoser

Todavía no existen aprendizajes de diagnóstico confirmados para ningún
servidor de este dominio. Este archivo se llena solo con causas raíz que
el agente mismo confirme en diagnósticos reales — no con incidentes
transitorios de una sola corrida ni con nada inventado de antemano.
Cuando haya varios servidores con hallazgos, organizar por sección
(`## <host>`) en vez de mezclar todo sin distinción.
