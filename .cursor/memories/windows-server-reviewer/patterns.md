# Patrones — windows-server-reviewer

Checklist que ya usa el proceso de este agente (ver su
frontmatter/instrucciones): servidor exacto identificado contra el
catálogo, archivo/comando exacto identificado, diff real, backup
concreto, plan de reversión ejecutable, validación posterior verificable,
sin comandos de la lista de prohibiciones permanentes, sin
`Get-WinEvent` sin `-MaxEvents`, sin secretos expuestos en el reporte,
aprobación acotada a la acción puntual en el servidor puntual. Patrones
reales (hallazgos recurrentes en cada servidor) se agregan solo cuando
se confirmen en una revisión real — todavía no hay ninguno.
